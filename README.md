# Youtube Clone
YouTube Clone is a React-based application that mimics the functionality of YouTube. It features video browsing, detailed video pages, user authentication, and channel management. With Redux for state management and React Router for dynamic navigation, the app ensures a seamless and responsive user experience, optimized with lazy loading.
## Features
1. **Seamless Video Experience**: Browse, view, and explore detailed video pages with title, description, views, and more.
2. **Channel Insights**: Dive into creator profiles showcasing subscriber counts and uploaded videos.
3. **Smart Search & Navigation**: Effortlessly search videos and channels with dynamic routing for personalized results.
4. **User-Centric Design**: Responsive UI, secure authentication, and collapsible drawer for streamlined usability.
5. **Optimized Performance**: Lazy loading, Redux-powered state management, and a custom 404 page for efficiency and reliability.
## Setup and Installation
1. `Clone` the Repository
``` bash
git clone https://github.com/syaloni06/Youtube_Clone.git
cd Youtube_Clone
```
2. Install Dependencies
- Ensure you have `Node.js` and `npm` installed.
``` bash
npm install
```
3. Install MongoDB and make a new connection.
4. Start the development server
- This will open the application in your default browser at http://localhost:5173/
``` bash
npm run dev
```
- If the project has a local server setup, run the appropriate command to start at http://localhost:5100/
``` bash
npm start
```
## Usage
1. **Video Exploration**: Browse the homepage to view and play videos, and click to explore detailed content.
2. **Search & Discover**: Use the search bar to find videos or channels with real-time updates based on your query.
3. **Channel Insights**: Visit creator channels to explore their content and gain deeper insights into their work.
4. **User Authentication**: Sign in for personalized experiences or sign up to unlock features like subscriptions.
5. **Seamless Navigation**: Access content with dynamic routing, responsive design, and an intuitive drawer menu for smooth navigation.
